# BYD DiLink Voice Assistant (99x)
### Offline Hybrid Voice Assistant for Automotive Head Units (Android 10+)

مساعد صوتي ذكي هجين يعمل بدون إنترنت (Offline Native)، مخصص لشاشات سيارات **BYD (DiLink 3.0 / 4.0 / 5.0)** على معالجات كوالكوم سنابدراجون (Qualcomm Snapdragon 665 / 6125 / 8155).

---

## 🚀 المميزات المعمارية الرئيسية (Core Architecture)

1. **محرك التوجيه فائق السرعة (Engine A - Fast Semantic Router):**
   - استجابة فورية لأوامر السيارة في أقل من **50 ملي ثانية**.
   - موجه دلالي يعتمد على تضمين الجمل (Sentence Transformer ONNX) مع بوابة ثقة محكمة ($\ge 70\%$) لتنفيذ الأوامر مباشرة وتخطي استهلاك المعالج.
   
2. **محرك الذكاء الاصطناعي الاحتياطي (Engine B - Local GGUF LLM):**
   - مبني على `llama.cpp` JNI لتشغيل نماذج ذكاء اصطناعي محلية خفيفة (Tiny LLMs مثل Qwen2.5 أو SmolLM).
   - حصر استخدام أنوية المعالج بـ **2 إلى 3 أنوية فقط** لحماية استقرار نظام السيارة ومنع ارتفاع الحرارة.

3. **التحكم بالسيارة عبر نوايا BYD (BYD DiLink Hardware Intents):**
   - تحكم بالتكييف (`byd.intent.action.AC_CONTROL`): ضبط درجات الحرارة مع حماية النطاق الآمن ($16.0^\circ\text{C} - 32.0^\circ\text{C}$)، سرعة المروحة ($1 - 7$).
   - النوافذ وفتحة السقف (`byd.intent.action.WINDOW_CONTROL`).
   - تدفئة المقاعد والوسائط المتعددة (Media Keys).

4. **التكامل عبر بروتوكول MCP (Model Context Protocol):**
   - أداة `screen_inspect`: استخراج شجرة عناصر الشاشة الحالية من خلال خدمة إمكانية الوصول (`AccessibilityService`) لتمكين المساعد من "رؤية" ما يعرض على الشاشة.
   - أداة `web_search`: جلب الأحداث والأخبار اللحظية عند توفر اتصال إنترنت في السيارة مع مهلة استجابة قصوى ثانيتين.

5. **سياق ديناميكي وذاكرة طويلة الأمد (Dynamic Context & Memory RAG):**
   - حقن إحداثيات GPS الدقيقة وتوقيت النظام في سياق المحادثة.
   - ذاكرة Room DB تسترجع تفضيلات السائق بناءً على الكلمات المفتاحية وحقنها للفة الحالية فقط لتوفير نافذة الذاكرة.

6. **تنقية النطق الصوتي (Voice-First TTS Sanitizer & Piper TTS):**
   - تنظيف مسبق للمخرجات: إزالة Markdown والإيموجي وتحويل الرموز والوحدات لكلمات مقروءة (`22°C` $\rightarrow$ `22 degrees Celsius`, `15km` $\rightarrow$ `15 kilometers`).
   - تشغيل نماذج VITS `.onnx` فائقة الطبيعية عبر Piper TTS مع الرجوع التلقائي لمولد الصوت المدمج في النظام.

7. **واجهة السيارة العائمة (Automotive HUD Floating Overlay):**
   - ويدجت عائم فوق خرائط الملاحة وتطبيقات السيارة (`TYPE_APPLICATION_OVERLAY`).
   - إخفاء تلقائي بعد 3 ثوانٍ من انتهاء المحادثة.

## 🛠️ هيكلية الوحدات (Project Modules)

```
99x/
├── app/                  # واجهة الإعدادات والتشخيص، الخدمة الخلفية، والنافذة العائمة
├── core-vehicle/         # طبقة التحكم بعتاد BYD والمحاكي الآمن
├── core-ai/              # موجه الأوامر ONNX، محرك llama.cpp، ومطهر الصوت
├── core-context/         # مزود GPS والتوقيت وقاعدة بيانات الذاكرة Room
├── core-mcp/             # عميل بروتوكول MCP وأدوات فحص الشاشة والويب
├── core-audio/           # التقاط الميكروفون، كلمة التنبيه، Vosk STT، و Piper TTS
└── release/              # حزمة APK الموقعة الجاهزة للتثبيت
```
